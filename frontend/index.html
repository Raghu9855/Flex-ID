About Multi-Class Intrusion Detection

FLEX-ID maps network flows across 13 distinct traffic categories including Benign, DoS attacks-Hulk, DoS attacks-Slowloris, DDoS attack-HOIC, FTP-BruteForce, SSH-Bruteforce, Infiltration, and SQL Injection.

Inputs undergo automated feature scaling using the serialized MinMaxScaler artifact to eliminate serving distribution skew before feedforward execution.
